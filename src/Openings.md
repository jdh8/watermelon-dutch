# Openings

|     | |
|-----|-|
| 1♣  | 11--23, 2+♣
| 1♦  | 11--23, 4+♦
| 1♥♠ | 11--20, 5+#
| 1NT | 15--17, 2--5♠, 2--5♥, 2--6♦, 2--6♣
| 2♣! | 21+, (5+♠♥ or 6+♦♣ or 24+)
| 2NT | 21--23, 2--4♠, 2--4♥, 2--6♦, 2--6♣

The [ACBL Basic Chart][ACBL] forbids a natural 2NT from bearing a void or a
singleton < Q.  Thus, 1♣♦ have to handle strong hands which are disqualified
from 2NT and lack a rebid after the 2♣ opening.

[ACBL]: https://web2.acbl.org/documentLibrary/about/Convention-Charts.pdf

## Basic+ agreements, optional

The agreements in this section requires the [ACBL Basic+ Chart][ACBL].

### Off-shape 2NT

Basic+ allows all very strong 2-level openings.

|     | |
|-----|-|
| 1♣  | 11--20, 2+♣
| 1♦  | 11--20, 4+♦
| 2NT | 21--23, 0--4♠, 0--4♥, 0--6♦, 0--6♣

### Preemptive 2NT

Basic+ allows 2NT to show 5+ 4+ minors.  The unusual 2NT is therefore permitted.

|     | |
|-----|-|
| 1♣  | 11--20, 2+♣
| 1♦  | 11--20, 4+♦
| 2♣! | 21+
| 2NT | 4--10, 5+♦, 5+♣
